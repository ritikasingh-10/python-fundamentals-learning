Python Learning Journey 🐍

Welcome to my Python learning repository.

I created this repository to build a strong foundation in Python before moving into Data Science libraries such as NumPy, Pandas, Matplotlib, and Scikit-learn.

The main focus is not just learning Python syntax, but understanding how to think logically and solve problems using Python.

🧠 My Learning Approach

For each topic, I try to follow this process:

Learn the Concept
       ↓
Understand Why It Is Used
       ↓
Write Small Examples
       ↓
Solve Practice Problems
       ↓
Debug Mistakes
       ↓
Apply the Concept to a Problem
       ↓
Document My Learning

The goal is to understand what, why, and how, rather than simply memorizing Python syntax.
